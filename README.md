## 📌 About

**rozzkuchhnaya** is a bilingual (Hindi + English) content platform built for students —
a daily "Word of the Day", practical study tips, curated learning resources, short
5-minute life lessons, tech write-ups, and a self-checking **mock test** module for
exam aspirants (JEE / SSC / general competitive exams).

It's a fully static, multi-page website — no backend, no build step — designed to be
fast, simple, and easy to keep updating with fresh content.

## ✨ Features

- 📅 **Word of the Day** — a new vocabulary word with meaning, every day
- 📚 **Study Tips** — practical, actionable strategies (goal-setting, active recall, etc.)
- 🧰 **Resources** — curated tool recommendations for students (e.g. Notion workflows)
- ⏱️ **5-Minute Reads** — short, high-impact life & learning lessons
- 🇮🇳 **Hindi Blogs** & 🇬🇧 **English Blogs** — separate sections for each language
- 💻 **Tech Blog** — write-ups on tools, projects, and things learned in tech
- 📝 **Mock Test module** — self-assessment tests for exam prep
- 💬 **Comments section** — readers can share feedback directly on the site
- 📱 Fully responsive — works cleanly on mobile, tablet, and desktop

## 📂 Project Structure

```
rozzkuchhnaya/
├── index.html            # Home page — word of the day, tips, resources
```

## ▶️ Running Locally

```bash
# 1. Clone the repository
git clone https://github.com/shivansh1512x/rozzkuchhnaya.git

# 2. Move into the project folder
cd rozzkuchhnaya

# 3. Open index.html directly in your browser,
#    or serve it locally for a better experience:
npx serve .
```
